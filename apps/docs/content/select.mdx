## Usage notes

Built on Radix Select. Remaining props go to the trigger button.

## Accessibility

- Trigger has `role="combobox"`; the list is a `listbox` with `option`s.
- Space, Enter or ↓ opens; ↑/↓ move; Home/End jump; typing jumps to a matching option; Escape closes and returns focus.
- `SelectGroup` labels its options for screen readers.
