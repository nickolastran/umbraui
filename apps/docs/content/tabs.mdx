## Usage notes

Built on Radix Tabs. For a sliding indicator see AnimatedTabs.

## Accessibility

- `tablist` / `tab` / `tabpanel` roles. ←/→ (or ↑/↓ when vertical) move and activate; Home/End jump.
- Tab moves from the active trigger into the panel, which is focusable.
- Give `TabsList` an `aria-label`.
